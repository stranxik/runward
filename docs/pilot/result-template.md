## The verdict, computed

The criterion was written before any data existed. It has two arms, and either one firing means the
pilot counts **against** the method:

| Arm | Test | Result |
|---|---|---|
| Unanswered questions did not fall | `U_after >= U_before` | ☐ fired ☐ did not fire |
| The method cost more than it saved | `(T_before - T_after) < O` | ☐ fired ☐ did not fire |

**Verdict**: ☐ counts for the method ☐ **counts against the method**

## What this is one data point of

One pilot, one repository, one engineer. It says nothing about a second repository and nothing about
an average. Written here rather than left to the reader, because a single measurement quoted without
its N is how an honest number becomes a dishonest claim.
