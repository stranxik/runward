## Sovereignty Graduated by Class of Data

> **Sovereignty is not a switch, it is a gradient.** It is decided per class of data crossing a port, not wholesale for a system.

For every port, each class of data crossing it carries a declared sovereignty level. Public reference data can live on a managed vendor runtime; internal business data raises the bar; regulated or personal data pushes placement toward the internal families, decided at field level, not system level. Sovereign by default wherever sovereignty costs only operations, gateway, memory, registry, execution, access control; the only tier where it can cost quality is the model, and the model port keeps sensitivity-based routing local and reversible, best available engine for ordinary data, sovereign engine for regulated data. The declared level lives in `execution-topology.md`, on the row of the port that data class crosses.
